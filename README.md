# Mock-up Gebruikersflow 2.0


[Edit in StackBlitz next generation editor ⚡️](https://stackblitz.com/~/github.com/ArisRosbach/mockup-gebruikersflow2.0)

Een UI/UX mockup project voor een vernieuwde gebruikersflow binnen het Zorgportaal.

Dit project bevat interactieve front-end concepten en designs gericht op:
- Een modernere gebruikerservaring
- Verbeterde navigatie
- Mobile first design
- Toegankelijkheid en overzicht
